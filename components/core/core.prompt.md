Core surface + status primitives: `Card`, `Badge`, `RatingBadge`.

```jsx
<Card hover>…</Card>
<Badge tone="green" icon={<Check/>}>Licensed & Insured</Badge>
<Badge tone="accent">24/7 Emergency</Badge>
<RatingBadge value={4.9} count={2148} size="lg" />
```

Card: `hover` lift for clickable cards, `pad`. Badge tones: blue·navy·accent·green·amber·gray·solid. RatingBadge renders fractional star fill.
