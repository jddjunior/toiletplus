## SEO Files

### sitemap.xml
- **Location**: `/sitemap.xml`
- **Purpose**: XML sitemap for search engine indexing
- **Update Frequency**: Monthly
- **Contains**: All pages with priority and change frequency

### robots.txt
- **Location**: `/robots.txt`
- **Purpose**: Guide search engine crawlers
- **Rules**: Allow all crawlers, disallow admin/private areas
- **Directives**: Crawl delay, request rate, sitemap reference
